# Third-party material

The four Bongo Cat PNG frames in `assets/` are byte-identical copies from
[saatvik333/wayland-bongocat](https://github.com/saatvik333/wayland-bongocat)
v2.0.2 at commit `9cd36c6b79d9271810054fb4e99793934bbae98b`. The left/right
paw mapping and 100/200 ms default timings match the same project.
`animation-preview.png` is a documentation montage of those frames.
